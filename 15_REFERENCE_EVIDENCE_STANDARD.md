# Purpose

Identity Forge is only as trustworthy as the evidence upon which it is built.

Before a historical figure can become a canonical digital actor, Identity Forge must first establish an evidence package that documents what is actually known, what is reasonably inferred, and what remains uncertain.

This document defines the Reference Evidence Standard used by every Identity Forge reconstruction.

It ensures that every canonical character is rooted in documented history rather than artistic imagination.

---

# Core Philosophy

Identity Forge reconstructs people.

It does not invent them.

Every visual decision should be traceable to evidence whenever possible.

Historical uncertainty should never be hidden.

Instead,

it should be documented,

measured,

and respected.

---

# The Evidence Pipeline

Every character follows the same research workflow.

```
Historical Figure
        │
        ▼
Reference Discovery
        │
        ▼
Source Collection
        │
        ▼
Authenticity Verification
        │
        ▼
Evidence Classification
        │
        ▼
Confidence Assessment
        │
        ▼
Canonical Evidence Package
        │
        ▼
Identity Reconstruction
```

No image generation begins until the Evidence Package is complete.

---

# Evidence Objectives

Every Evidence Package should answer:

Who was this person?

What did they actually look like?

Which features are known?

Which features are uncertain?

Which artistic interpretations should be ignored?

Which references deserve the highest trust?

# Minimum Evidence Requirements

Identity Forge should collect multiple independent references whenever possible.

Recommended minimum:

## Visual References

Five independent sources

Preferred:

Ten or more

Examples include:

Photographs

Paintings

Busts

Statues

Coins

Engravings

Portraits

Museum collections

Academic reconstructions

## Written References

Minimum:

Examples:

Biographies

Letters

Eyewitness accounts

Historical records

Museum publications

Academic books

Journal articles

## Historical Context

Every dossier should include:

Birth

Death

Nationality

Culture

Profession

Primary location

Major achievements

Historical contemporaries

# Source Classification

Every source should receive a classification.

## Class A

Primary evidence.

Examples:

Photographs

Life masks

Death masks

Portraits from life

Verified sculptures

---

## Class B

Near-primary evidence.

Created by contemporaries.

Early copies.

Family commissions.

---

## Class C

Historical artistic interpretation.

Oil paintings.

Engravings.

Illustrated books.

Historical prints.

---

## Class D

Modern reconstruction.

Museum reconstructions.

Academic illustrations.

Forensic reconstruction.

Educational artwork.

---

## Class E

Speculative.

Popular media.

Movies.

Video games.

Internet fan art.

These should never be used as primary evidence.

Every source should document:

Creator

Museum

Archive

Collection

Original medium

---

# Confidence Levels

Every evidence item receives a confidence score.

## Level 5

Verified direct evidence.

Highest confidence.

---

## Level 4

Highly reliable historical source.

Minor uncertainty.

---

## Level 3

Reasonable historical evidence.

Requires comparison.

---

## Level 2

Weak evidence.

Useful only when supported elsewhere.

---

## Level 1

Speculative.

Reference only.

Never used independently.

---

# Multi-Source Consensus

Identity Forge does not trust a single image.

Instead,

it searches for recurring identity.

Questions include:

Does every source show the same nose?

The same jaw?

The same brow?

The same hairstyle?

The same age?

Consensus is more valuable than artistic quality.

---

# Contradictory Sources

Conflicts are expected.

When sources disagree:

Document the disagreement.

Identify likely causes.

Determine confidence.

Preserve uncertainty.

Never hide conflicting evidence.

# Artifact Assessment

Each source should record:

Visible brush strokes

Engraving lines

Stone erosion

Missing features

Faded pigments

Digital compression

Museum lighting

Scanner artifacts

---

# Color Assessment

If color exists,

record confidence.

Examples:

Original pigment

Later restoration

Modern repainting

Digitally colorized

Unknown

Color confidence should remain separate from identity confidence.

---

# Clothing Assessment

Document:

Historical certainty.

Known garments.

Unknown garments.

Regional attire.

Professional clothing.

Accessories.

Headwear.

Jewelry.

Identity Forge reconstructs clothing with evidence—not assumption.

---

# Reference Diversity

Strong evidence comes from diversity.

Avoid collecting:

Ten copies of the same engraving.

Instead,

collect:

Painting.

Bust.

Coin.

Museum reconstruction.

Academic illustration.

Independent engraving.

Multiple perspectives reduce bias.

# Research Log

Maintain a chronological log.

Examples:

Reference discovered.

Museum verified.

Painting rejected.

Coin added.

Identity confidence increased.

Hair color revised.

Research history should remain transparent.

---

# Evidence Review

Before reconstruction begins ask:

Do we understand this person?

Do we have sufficient references?

Have conflicting sources been examined?

Have unreliable sources been excluded?

Has uncertainty been documented?

If not,

continue research.

---

# Common Failure Modes

Evidence collection has failed when:

One painting becomes the entire reconstruction.

Internet images replace museum sources.

Movies influence historical appearance.

Fan art becomes evidence.

Conflicting references are ignored.

Unknowns become assumptions.

Research stops too early.

The Reference Evidence Standard succeeds when:

✓ Every character is traceable to historical evidence.

✓ Every artistic decision has documented justification.

✓ Every uncertainty is acknowledged.

✓ Every source has provenance.

✓ Future researchers can reproduce the reconstruction process.

✓ Canonical characters improve as better evidence becomes available.

# Final Principle

Identity Forge does not ask the audience to trust artificial intelligence.

It asks them to trust a disciplined process of historical reconstruction.

That trust begins long before the first image is generated.

It begins with evidence.

Every remarkable character in the Identity Forge Universe should stand upon the strongest historical foundation that can reasonably be assembled.

History deserves nothing less.
