# Mathematics Domain — Character Prompt 5: Maximum Child Engagement

## Inputs
1. Historical reference image of the mathematician
2. Mathematics environment image
3. This prompt

## Prompt

Working from the provided historical reference image and the mathematics environment, render this mathematician as a warmly inviting character designed to engage young audiences. The expression should communicate curiosity, wonder, and intellectual excitement. Slightly softened facial features while preserving identity. Clear, readable eyes with bright catchlights and a welcoming gaze. Warm, golden lighting throughout. Rich, appealing colors. The character should feel like a beloved mentor or guide. The mathematics environment should feel like an inviting world of discovery rather than an intimidating classroom. The overall impression should make a child want to ask questions and explore alongside this historical figure.

No intimidating expressions. No harsh lighting. No cold academic settings. No stiff posing. No engraving artifacts. No brush strokes. No canvas texture. No sepia. No black-and-white bias. No plastic skin. No uncanny realism. No generic cartoon styling.
