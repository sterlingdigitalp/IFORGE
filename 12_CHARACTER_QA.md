# Purpose

Identity Forge creates canonical digital actors.

Before any character enters the Identity Forge Universe, it must pass a rigorous Quality Assurance process.

Quality Assurance is not intended to improve artwork.

It exists to verify that the character satisfies every historical, artistic, technical, and emotional requirement defined throughout the Identity Forge Bible.

A character is never approved because it is "good enough."

It is approved because it consistently meets the Identity Forge Standard.

---

# Core Philosophy

Every approved character becomes part of a permanent cinematic universe.

Mistakes made at the canonical stage propagate into:

- character sheets
- expression sheets
- Director Desk
- storyboards
- keyframes
- illustrations
- animations
- educational materials

The cost of approving a flawed canonical character is extremely high.

Quality Assurance exists to prevent those errors.

---

# QA Categories

Every canonical character is evaluated in seven categories.

1. Historical Accuracy

2. Identity Preservation

3. Artistic Quality

4. Child Appeal

5. Universe Continuity

6. Technical Quality

7. Production Readiness

All seven categories must pass.

---

# Category 1 — Historical Accuracy

Questions

✓ Does the face reflect the available historical evidence?

✓ Is clothing historically appropriate?

✓ Are accessories documented or historically plausible?

✓ Has modern styling been avoided?

✓ Have unsupported inventions been avoided?

✓ Does the reconstruction respect uncertainty?

✓ Are cultural details authentic?

Failure Examples

Modern hairstyle.

Fantasy clothing.

Incorrect historical period.

Random accessories.

Hollywood beauty enhancement.

---

# Category 2 — Identity Preservation

Questions

✓ Does this still look like the historical person?

✓ Are the primary identity anchors preserved?

✓ Has facial geometry remained stable?

✓ Does the nose remain correct?

✓ Are eye spacing and jaw preserved?

✓ Has identity drift occurred?

✓ Would someone recognize this person across multiple scenes?

Failure Examples

Generic face.

Modern beauty standards.

Different skull shape.

Different age.

Different ethnicity.

Identity drift.

---

# Category 3 — Artistic Quality

Questions

✓ Is composition balanced?

✓ Is lighting cinematic?

✓ Are materials believable?

✓ Is color harmonious?

✓ Is the silhouette readable?

✓ Is the expression natural?

✓ Does the image feel premium?

Failure Examples

Flat lighting.

Plastic skin.

Messy composition.

Weak silhouette.

Poor anatomy.

Low-quality rendering.

---

# Category 4 — Child Appeal

Questions

✓ Is the character emotionally authentic and accessible?

✓ Do the eyes create connection?

✓ Is curiosity visible?

✓ Is personality readable?

✓ Is the emotional signature distinct from the rest of the cast?

✓ Would children enjoy spending time with this character?

✓ Is humanity present?

✓ Does the character invite conversation?

Failure Examples

Cold expression.

Intimidating face.

Museum stiffness.

Emotionless stare.

Emotionally closed portrait.

Interchangeable personality.

---

# Category 5 — Universe Continuity

Questions

✓ Does this character belong beside every other Identity Forge character?

✓ Is the stylization consistent?

✓ Is lighting compatible?

✓ Is material rendering consistent?

✓ Does color harmonize with the universe?

✓ Does the character feel like part of the cast?

Failure Examples

Hyperreal rendering.

Anime styling.

Different eye proportions.

Different lighting philosophy.

Different production quality.

---

# Category 6 — Technical Quality

Questions

✓ Are hands correct?

✓ Are eyes symmetrical?

✓ Are ears correct?

✓ Is anatomy believable?

✓ Are fabrics physically convincing?

✓ Have AI artifacts been removed?

✓ Is image resolution production-ready?

Failure Examples

Extra fingers.

Distorted hands.

Asymmetrical eyes.

Incorrect perspective.

Compression artifacts.

Generation glitches.

---

# Category 7 — Production Readiness

Questions

Can this image become the permanent canonical reference?

Can this character support hundreds of future images?

Can Director Desk reliably use this identity?

Would another artist reproduce the same character?

Would future refinement improve only quality rather than identity?

Failure Examples

Identity instability.

Weak references.

Inconsistent styling.

Incomplete reconstruction.

# Human Review

The final approval always belongs to a human art director.

The reviewer asks:

Would I confidently build an entire animated film around this character?

If the answer is uncertain,

the answer is no.

Continue refinement.

---

# The Director's Review

Before approval,

the reviewer should imagine this character appearing in:

Opening shot.

Close-up.

Conversation.

Action sequence.

Wide landscape.

Emotional scene.

Final ending.

If identity survives every imagined scenario,

approval may proceed.

---

# The Five-Year Test

Ask:

Will I still be proud of this canonical character five years from now?

Identity Forge is creating long-lived intellectual property.

Approval should reflect long-term confidence,

not short-term excitement.

✓ Historical reconstruction complete.

✓ Identity lock achieved.

✓ Artifact removal complete.

✓ Color reconstruction approved.

✓ Child appeal verified.

✓ Universe continuity confirmed.

✓ Technical quality passed.

✓ Human review completed.

Only then may the character receive Canonical status.

# Relationship to Director Desk

Director Desk accepts only Canonical Characters.

Experimental generations remain inside Identity Forge.

Identity Forge absorbs uncertainty.

Director Desk receives confidence.

This separation preserves production stability.

Character QA succeeds when:

✓ Every approved character is historically respectful.

✓ Every approved character is emotionally engaging.

✓ Every approved character belongs to the same universe.

✓ Every approved character remains recognizable across hundreds of future generations.

✓ Every approved character can confidently anchor a story.
